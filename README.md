# Java

Repositório dedicado ao aprendizado e prática da linguagem Java, com exercícios, pequenos projetos e aplicações simples focadas em lógica, orientação a objetos, estruturas de dados e desenvolvimento back-end.

## Objetivo

Explorar os conceitos fundamentais da linguagem Java por meio de projetos práticos, reforçando habilidades como:

- variáveis e tipos de dados
- controle de fluxo
- orientação a objetos
- classes e objetos
- encapsulamento
- herança e polimorfismo
- coleções
- lógica de programação aplicada

## Conteúdo

Este repositório reúne exemplos e projetos voltados para:
- estudo da linguagem Java
- prática de programação orientada a objetos
- desenvolvimento de aplicações simples
- aprendizagem contínua e resolução de problemas

## Tecnologias

- Java

- Lógica e algoritmos

## Como executar

1. Clone o repositório:
```bash
git clone https://github.com/seu-usuario/Java.git
```

2. Acesse a pasta do projeto:
```bash
cd Java
```

3. Compile o programa:
```bash
javac NomeDoArquivo.java
```

4. Execute o programa:
```bash
java NomeDoArquivo
```
